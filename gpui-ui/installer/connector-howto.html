Zinc Connector

Save web pages, PDFs and references into your Zinc library from Chrome or Edge, with or without the app open.

Setup has already registered the helper program the extension talks to. The browser itself does not let an installer add an extension, so do this once (about thirty seconds):

  1. Open chrome://extensions in Chrome (or edge://extensions in Edge).
  2. Turn on Developer mode (top right in Chrome, left sidebar in Edge).
  3. Click Load unpacked and pick this folder: the extension folder next to this page (inside the connector folder of your Zinc installation)
  4. Check the extension's ID reads pakgagonakcalfbmckaolkpidcojacaf. It is fixed, and it is the ID Setup allowed to talk to the helper. Pin the toolbar button if you like, then open any article and click it.
Keep the folder where it is: the browser loads the extension from it every time it starts. After a Zinc update, open the extensions page and click the reload arrow on the extension to pick up the new version.

Prefer the official Zotero Connector from the Chrome Web Store or the Edge Add-ons store? It works too, but only while Zinc is open (the app answers on Zotero's port 23119). Keep just one of the two connectors on a browser, or every page shows two Save buttons.

Remove it: delete the extension in the extensions page, and untick or remove the connector in Zinc's uninstaller.
